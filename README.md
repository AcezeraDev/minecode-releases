# MineCode Desktop

A Mine programando no seu computador, não só no navegador.

[Baixar para Windows 10/11, 64 bits](https://github.com/AcezeraDev/minecode-releases/releases/latest/download/MineCodeSetup.exe)

[Abrir o Minerva](https://minerva-liart.vercel.app) · [Versão e arquivos](https://github.com/AcezeraDev/minecode-releases/releases/latest)

Este repositório contém apenas os instaladores públicos do MineCode. O aplicativo ainda não tem assinatura digital: o Windows pode exibir um aviso do SmartScreen. Confira a origem do arquivo antes de instalar.

O aplicativo é gratuito. Provedores de IA em nuvem podem cobrar pelo uso. Modelos locais pelo Ollama funcionam sem internet depois de instalados e baixados.
